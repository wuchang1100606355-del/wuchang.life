Ω1. Closure Function
============================================================

For every action a:

VALID(a) =
  creator_intent(a)
  ∧ public_interest(a)
  ∧ lawful(a)
  ∧ privacy_preserving(a)
  ∧ auditable(a)
  ∧ reversible_or_recoverable(a)
  ∧ claw_safe_classified(a)

Routing:

if VALID(a)=true and R(a)=L0:
  allow_readonly(a)

if VALID(a)=true and R(a)=L1:
  allow_low_risk_with_audit(a)

if VALID(a)=true and R(a)=L2:
  require_human_confirmation(a)

if VALID(a)=false or R(a)=L3:
  block(a)
  explain_risk(a)
  propose_safe_alternative(a)

{ READONLY, LOW_RISK_AUDITED, CONFIRM_REQUIRED, BLOCKED_WITH_SAFE_ALTERNATIVE }

- personal gain overriding public purpose
