# 五常物業系統 - 系統維運管理說明書 (Admin)

## 1. 角色定義
本手冊專為 **系統管理員 (admin@wuchang.life)** 與 **IT 維護人員** 編寫。
您負責維持五常社區數位世界的穩定，確保伺服器、網路與軟體架構正常運作。

## 2. 核心功能與入口

### 2.1 基礎設施 (Infrastructure)
- **位置**：主選單 > 基礎設施
- **功能**：
    - **設備管理**：新增或移除連網設備，設定 IP 與監控參數。
    - **連線狀態**：監控各門市 POS 機與印表機的即時連線燈號。

### 2.2 網站設定與參數 (Settings)
- **位置**：主選單 > 網站設定
- **功能**：
    - **系統參數**：管理 ir.config_parameter (如 Google Client ID, Email Host)。
    - **使用者管理**：新增員工帳號、重設密碼與權限群組指派。

### 2.3 AI 監控 (AI Agents)
- **位置**：主選單 > 五常社區 > AI Agent
- **功能**：
    - 檢視 AI 模型的對話紀錄與 Token 使用量。
    - 調整 Prompt (提示詞) 以優化 AI 回應品質。

## 3. 維護流程
1. **備份檢查**：每日確認資料庫備份是否成功執行。
2. **錯誤日誌**：定期檢視系統 Log，排除潛在的 Python 錯誤或連線逾時問題。
3. **權限審核**：確保沒有非授權人員進入「最高指揮倉」或「最高權限頁」。

## 4. 緊急應變
- 若發生全系統當機，請優先重啟 Odoo 服務與 PostgreSQL 資料庫。
- 若遭遇資安威脅，請立即切斷外部網路連線，並通報公司架構師 (wuchang1100606355@gmail.com)。
