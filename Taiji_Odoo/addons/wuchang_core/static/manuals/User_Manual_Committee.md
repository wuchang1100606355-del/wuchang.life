# 五常物業系統 - 管委會使用說明書
## 1. 角色定義
本手冊專為 **公寓大廈管理委員會成員 (主委、監委、財委等)** 編寫。
您是社區自治的核心，負責決策、監督與溝通。五常物業系統是您最強大的輔助工具，讓管理透明化、決策數據化。

## 2. 核心功能
### 2.1 社區資料管理
- **社區基本資料**：查看社區總戶數、公設配置。
- **棟別與住戶**：掌握各棟別、樓層與區分所有權人資訊 (個資嚴格保護)。
- **管委會名冊**：維護歷屆委員名單與任期，確保傳承不中斷。

### 2.2 住戶反映處理
- **報修與投訴**：即時查看住戶透過系統提交的報修或投訴。
- **處理進度追蹤**：監控物業團隊的處理狀態 (已通報 -> 處理中 -> 已完成)。
- **案件分析**：透過 AI 協助，分析常見問題 (如：特定電梯常故障、某時段噪音頻繁)，作為改善決策依據。

### 2.3 財務與行政 (搭配「老陳」AI 顧問)
- **財務報表審閱**：線上查閱每月財務報表，明細清楚，杜絕帳務不清。
- **會議輔助**：利用 AI 快速生成會議議程、記錄決議事項。
- **法規諮詢**：隨時詢問系統內建的「老陳」AI，獲取公寓大廈管理條例的專業見解。

## 3. 每日必做 (Daily Routine)
1. **登入系統**：使用您的委員專屬帳號登入。
2. **查看儀表板**：關注是否有緊急的住戶反映或待審核事項。
3. **溝通協調**：透過系統留言功能，與物業人員或其他委員進行非同步溝通。

## 4. 常見問題 (Q&A)
- **Q: 住戶個資安全嗎？**
  - A: 絕對安全。系統採用嚴格的權限控管，僅有授權人員可查看必要資訊，並符合個資法規範。
- **Q: 我不懂法規怎麼辦？**
  - A: 請呼叫系統內的「老陳」AI，他有15年物業經驗，能告訴您該怎麼做才合法合情合理。
- **Q: 如何交接給下一屆？**
  - A: 系統資料雲端化，所有歷史紀錄完整保存，下一屆委員上任後直接沿用，無縫接軌。
