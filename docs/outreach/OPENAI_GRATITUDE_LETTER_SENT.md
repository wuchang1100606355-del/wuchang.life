【五常智慧雲｜OpenAI / ChatGPT 感謝信寄送紀錄】

事件：
新北市三重區五常社區發展協會與發明人江政隆，已向 OpenAI / ChatGPT 團隊寄出感謝信與行銷使用授權聲明。

核心感謝：
感謝 ChatGPT AI 對五常智慧雲 Wuchang Smart Cloud 在主權 AI、社區服務 AI、資料治理、無障礙服務、Odoo 公益平台、3D 空間照準、動態 QR、語音服務與小 J Live Operator 架構整理上的賦能。

公益意圖：
本系統特別致力於賦能盲人、視覺障礙者、身心障礙者、弱勢居民與需要社區支持之使用者。

授權邊界：
OpenAI 得引用感謝聲明之全部或部分內容作為公開行銷、案例介紹、公益科技推廣、網站內容、簡報、社群貼文、新聞稿或廣告素材使用。
但不得暗示本系統已正式營運，不得取得本會會員資料、系統密鑰、未公開技術文件、會員名冊、住戶資料或任何非公開資料。
本授權不構成專利權、著作權、商標權、營業秘密、資料庫權利或系統控制權之移轉。
