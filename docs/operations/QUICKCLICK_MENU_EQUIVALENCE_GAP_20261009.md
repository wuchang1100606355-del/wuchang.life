## 操作流程

選取清單商品 → 批次修改預覽 → 逐項比較商品／修改項目／前值／後值 → 送審 → 原帳號核准 → 原帳號再次確認套用。送審及核准均不修改商品。回復從已套用申請建立新申請，再走同一流程；不改寫歷史。
