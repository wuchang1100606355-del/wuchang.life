## 手寫規則

- 只寫真實菜單品名，不寫 GPT 生成品名或促銷語。
- 不寫會員姓名、電話、LINE ID、地址或其他個資。
- 不記信用卡或外部付款資料；本輪只支援現金。
- POS 恢復後，以手寫單補登正式 POS，補登後把 POS 訂單號寫回紙本。

## 異常處理

- 金額不確定：先找店長確認。
- 客人取消：手寫單標記取消，不補登 POS。
- 已收現但未補登：店長先保留紙本，晚間對帳時補登或註記。
