# 小J志工外送 LINE Rich Menu 草案

狀態：PLANONLY / DESIGN ONLY
目的：讓居民用最少文字輸入提出外送協助需求。

## Rich Menu 主按鈕

1. 申請外送協助
2. 查看申請進度
3. 取消申請
4. 聯絡協會人員
5. 志工接單入口
6. 使用說明

## 申請外送協助流程

1. 選擇需求類型：餐點 / 文件 / 日用品 / 其他
2. 選擇大約區域：B棟 / C棟 / 社區周邊 / 其他
3. 選擇希望時間：今天中午 / 今天晚上 / 明天 / 其他
4. 詢問是否涉及代付款、藥品、貴重物或緊急事件
5. 若高風險，直接轉人工 / DLQ
6. 若低風險，產生 delivery_request_draft

## 個資硬牆

- LINE 階段不要求輸入完整身分證、完整電話、完整門牌。
- 精確個資只留協會依法物理控管邊界。
- 雲端 lane 只可接收 redacted_summary / hash / non-PII shard。
- 志工未接單前只看區域級資訊。

## PLANONLY 邊界

- LINE 只建立草稿，不自動派單。
- 高風險請求需人工審核。
- AI 不可直接完成派單或結案。
- Odoo 本階段仍為預留，不寫入。
