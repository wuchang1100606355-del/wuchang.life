## Why Continue

## What To Adjust

- Narrow the first wedge to Odoo/POS/cafe/community local operations.
- Avoid broad novelty claims.
- Avoid broad autonomous agent claims.
- Use "governance console" and "safety layer" language.
- Keep MVP read-only and local-first.
- Prepare clean-room implementation discipline before any code reuse.
