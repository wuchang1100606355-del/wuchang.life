# D8 Public-Safe One-Pager V2

## What Is D8?

D8 Total Field Agent Governance Console is a local-first safety console for teams using AI agents in real work.

Before an AI-assisted task proceeds, D8 checks local status, alerts, redteam history, and guard evaluations. It then records a clear decision such as PASS, WARN, HOLD, or BLOCK.

## Who Is It For?

- Cafe and community operators using Odoo/POS.
- Small teams using AI coding agents.
- Local-first organizations that need human-reviewed AI operations.

## First Pilot

The first pilot is designed for a cafe/Odoo/POS setting:

- read-only evidence,
- no payment capture,
- no POS order write,
- no member plaintext,
- human-approved runtime action only.

## Why It Matters

AI agents can be useful, but they need boundaries. D8 helps teams check what is safe to show, what must be held, and what needs human approval.

## What D8 Shows In A Demo

- Local status.
- Alerts.
- Redteam history.
- Guard evaluations.
- Voice/text dry-run.
- Read-only Odoo/POS bridge.
- Sealed report and readiness scorecard.

## What D8 Does Not Claim

- It does not claim absolute safety.
- It does not claim production release readiness.
- It does not claim patent approval.
- It does not replace Odoo, POS, Codex, Claude Code, Cursor, or other tools.
- It does not expose internal-only reasoning, dictionaries, weights, credentials, or WHY_IT_RUNS material.

## Pilot Offer

A controlled local pilot can verify whether operators can use D8 to run status, preflight, alerts, redteam review, read-only POS/Odoo evidence, and sealed reporting without unsafe runtime action.

## Suitable For Cooperation Discussion

D8 is ready for public-safe cooperation discussion and controlled local pilot planning. Production use requires later human approval, testing, and release gates.
