# DRS / MUS 開發者建議標準與最低可用標準

## 核心定義

DRS：Developer Recommendation Standard，開發者建議標準。  
MUS：Minimum Usable Standard，最低可用標準。

## 核心原則

MUS 先守門，DEV 後導引；Q 只看趨勢，不得覆蓋單量安全界線。

## 專利定盤句

本發明之場量化引擎接收一意圖封包，該意圖封包包含開發者方向符合度、開發者建議值、身份可信度、路權合法度、Guard 可通行度、ADI 可留證度、資料敏感度、幻覺風險、外送風險及場熵風險。系統先依最低可用標準判斷各單量是否突破安全界線；若任一單量突破界線，該意圖封包不得因場質總分或開發者建議值較高而被放行，而應導入只讀、隔離、人工確認或路由死信箱流程。
