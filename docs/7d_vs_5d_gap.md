# 7D vs 5D 差距量化

## 核心公式

```text
7D = [x, y, z, time, scale] + [heaven, earth]
```

## 量化結果

| 指標 | 數值 |
|---|---:|
| 5D 維度數 | 5 |
| 7D 維度數 | 7 |
| 新增維度 | 2 |
| 相對 5D 擴張 | 40% |
| 5D 作為 7D 前綴佔比 | 71.43% |
| 八陣 opcode | 3 bit |
| 八陣狀態 | 8 |
| 預設粒度 G=10 時狀態空間倍率 | 100x |

## 解讀

5D 負責定位狀態；7D 在原五維前綴上新增 heaven / earth，使狀態可以進入全域治理與本地承載的 Runtime 場。

這裡的 100x 是等粒度狀態可區分度，不是原始資料量。
