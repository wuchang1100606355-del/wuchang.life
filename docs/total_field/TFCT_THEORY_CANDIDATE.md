# Total Field Convergence Theory／全場收斂理論 — Candidate

Status: `CANDIDATE`

## 1. Purpose and boundary

**Total Field Convergence Theory／全場收斂理論（TFCT）**提出一組候選理論，用於描述 Event 如何被 Observation 捕捉，如何經由 Projection 形成治理 Field，以及所有治理場如何在約束下收斂為 Total Field State（TFS）。

本文件只區分定義、候選公理、候選原則、待證命題與 Open Problems。定義不等於證明；候選公理與候選原則須經獨立審查；待證命題在完成證明前不得視為成立。

## 2. Core concepts

### 2.1 Event

**Event 是不可再分割、可識別、可引用、可觀測的 Occurrence。** Event 是 Observation、Projection、Field 與 TFS 的共同指涉起點；它不等同於任何單一觀察、描述或治理判斷。

Event 必須符合下列候選公理：

- **E1 唯一性（Uniqueness）**：在明確的事件邊界內，每一 Event 具有唯一指稱；兩個不同 Event 不得被同一指稱混為一體。
- **E2 不可變性（Immutability）**：Event 一旦依其事件邊界成立，其已發生內容不得被後來的 Observation 或治理判斷回溯改寫。後續修正形成新的 Observation，不改變 Event 本身。
- **E3 可引用性（Referentiality）**：Event 必須能被不同 Observation 明確指向，且引用不得依賴未明示的語境。
- **E4 可驗證性（Verifiability）**：Event 的指稱與事件邊界必須能依已聲明的觀測條件接受獨立查核；不可查核的主張不得被當作已確認 Event。

### 2.2 Observation

**Observation 是在特定條件下對 Event 的捕捉與記錄。** 特定條件至少須界定觀測觀點、適用範圍與形成依據；未確定、缺失或相互衝突的內容必須保持可辨識。

Observation 不創造 Event，也不等同 Event。不同條件可形成不同 Observation；差異必須保留至治理判斷，不得以未聲明方式合併或消除。

**沒有明確 Observation，不得產生治理 Field。**

### 2.3 Projection

**Projection 是將明確 Observation 依治理觀點映射為 Field 內容的關係。** Projection 不等同來源 Observation，也不得創造來源中不存在的 Event 事實。任何與治理判斷相關的省略、轉換或不確定性都必須明示。

### 2.4 Field

**Field 是 Event 在治理觀點下的完整狀態投影。** 它由明確 Observation 經 Projection 形成，並保留治理判斷所需的事件指涉、狀態關係、約束與未決資訊。

Field 必須符合下列候選公理：

- **F1 投影性（Projectivity）**：Field 必須由明確 Event 與 Observation 經已聲明的 Projection 形成。
- **F2 不可獨立（Non-independence）**：Field 不得脫離其 Event、Observation 與 Projection 而獨立成立，也不得反向創造 Event。
- **F3 治理資訊守恆（Governance Information Conservation）**：足以改變治理判斷的資訊不得在 Projection 中無聲消失，Field 也不得加入沒有明確來源的治理資訊。
- **F4 可逆驗證（Reversible Verification）**：每一影響治理判斷的 Field 主張，都必須能回溯至 Event、Observation 條件與 Projection 關係，以接受獨立查核。
- **F5 一致性（Consistency）**：同一 Event 的多個 Field 不得隱藏彼此矛盾；尚未解決的衝突必須保持明示，並阻止其被誤認為已收斂狀態。

### 2.5 Total Field State (TFS)

**Total Field State（TFS）是所有治理場一致性收斂後，唯一滿足全部治理約束的狀態。** 這是 TFS 的定義性目標，不是唯一性已獲證明的聲明。

一個狀態只有在下列條件全部成立時，才可被提出為 TFS 候選：

1. Event 與所有相關 Observation 均有明確指涉；
2. 所需 Projection 與治理 Field 均已形成；
3. 全部適用治理約束已被納入判斷；
4. 沒有被隱藏或尚未處理的衝突；
5. 所有治理場在同一狀態下同時滿足其治理約束；
6. 該狀態可依 Event、Observation 與 Projection 關係接受驗證。

### Required Theorem T1 — TFS uniqueness

命題：對同一 Event、同一組明確 Observation、同一組 Projection、同一組治理約束與同一優先原則，滿足全部治理約束的 TFS 至多一個。

Status: `UNPROVEN`。

TFS 的「唯一」不能僅由定義推出；在 T1 完成證明前，不得宣稱一般情形下的 TFS 唯一性已成立。TFS 的存在性、有限步收斂與跨觀點等價性亦不由本節自動成立。

## 3. Candidate principles

### 3.1 Consistency Principle／一致性原則

所有治理 Field 必須能在同一候選狀態下同時滿足其適用約束。任何未解衝突都必須保持明示；只要衝突仍足以影響治理判斷，就不得將候選狀態視為 TFS。

### 3.2 Governance Principle／治理原則

Field 的形成、約束、優先關係與判斷依據必須明確。Observation 或 Projection 不得自行取得治理決定權；只有完成全部適用治理約束的判斷，才可提出新的 TFS 候選。

### 3.3 Separation Principle／分離原則

Event、Observation、Projection、Field 與 TFS 是相互關聯但不可互相取代的理論對象：Event 是發生事項，Observation 是條件化捕捉與記錄，Projection 是映射關係，Field 是治理觀點下的完整狀態投影，TFS 是治理場一致性收斂後的目標狀態。

## 4. Candidate convergence sequence

候選的理論順序如下：

1. **Event identification**：依 E1–E4 界定 Event。
2. **Observation formation**：在明確條件下捕捉並記錄 Event。
3. **Projection formation**：依治理觀點形成 Field 內容。
4. **Field verification**：依 F1–F5 檢查來源、資訊守恆、可逆驗證與一致性。
5. **Constraint judgment**：納入全部適用治理約束及其優先關係。
6. **Convergence judgment**：判斷是否存在同時滿足全部治理約束的狀態。
7. **TFS candidacy**：只有完成前述條件的狀態才可被提出為 TFS 候選。

此順序表達理論依賴，不構成存在、唯一或有限步收斂的證明。

## 5. Open Problems

下列問題尚未解決，不得表述為已成立事實：

1. 對不同 Event 類型，必要且充分的 Observation 條件為何？
2. 如何形式化判定 Event 的不可再分割邊界？
3. 如何證明 Projection 完整保留所有會改變治理判斷的資訊？
4. 如何證明 F4 所要求的回溯查核在各治理觀點下等價？
5. 在何種條件下，滿足全部治理約束的狀態必然存在？
6. Required Theorem T1 的充分條件與完整證明為何？
7. 在何種條件下，所有治理場會在有限步內收斂？
8. 不同觀測觀點形成的治理 Field，何時可判定為等價？
9. 多個治理約束的優先原則如何組合，並如何處理不可約衝突？
10. Observation 條件發生變更時，如何維持 Event 指涉與既有治理意義？

## 6. Candidate conclusion

全場收斂理論以 Event 為不可混同的指涉起點，以 Observation 作為 Field 形成的必要前提，以 Projection 保持治理資訊與可逆驗證，並以 Consistency、Governance、Separation 三項原則界定 TFS 候選。E1–E4、F1–F5 與三項原則仍屬候選基線；TFS 唯一性為 `Required Theorem / UNPROVEN`，Open Problems 在完成獨立論證前保持未決。
