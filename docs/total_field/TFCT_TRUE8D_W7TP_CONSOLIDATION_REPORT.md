## 1. Adopted definitions

This consolidation keeps four layers separate:

1. **Theory** — Total Field Convergence Theory defines Event, Observation, Projection, Field, and Total Field State (TFS).
2. **Mathematics** — projection functions, Constraint Hypergraph, Priority Policy, finite stopping conditions, fixed-point obligations, and equivalence conditions.
3. **Engineering** — TRUE8D governance, W7TP generative transmission, candidate expressions, verifiers, adapters, and ALLOW-only commit.
4. **Deployment** — nodes, organizational instances, Living Lab demonstrations, and protected deployment governance.

The adopted TRUE8D boundary is:

- D1 = Intent Field
- D2 = State Field
- D3 = Coordinate Field
- D4 = Evidence Field
- D5 = Execution Field
- D6 = Sovereign Privacy Field
- D7 = Generative Transmission & Resource Routing Field
- D8 = Red-Team Detour Alert & Quarantine Field

D3 remains an abstract Coordinate Field. This candidate does not select a geographic, Cartesian, graph, tensor, symbolic, or other coordinate model.

Generative transmission is the use of state-field packets, references, lookup material, reconstruction conditions, equivalent-state generation, and Total Field verification. It is not file moving, cloud synchronization, backup, download, decryption, or a claim that arbitrary existing files are available through small packets.
