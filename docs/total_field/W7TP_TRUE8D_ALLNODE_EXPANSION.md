## 安全邊界

本次盤點僅讀取：

- 路徑
- 檔案大小
- 修改時間
- 節點名稱
- 檔名/路徑關鍵字

本次盤點不讀取：

- 檔案內容
- secrets
- credentials
- keys
- vault
- member plaintext
- database content

## 紅隊規則

紅隊不管智財、專利、財務、資源、效能數據、技能管理。

紅隊只管：

- 有沒有繞
- 有沒有重複研究
- 有沒有重新定義
- 有沒有未推進交付物
- 是否需要 HOLD / DENY / SANDBOX_ONLY / HUMAN_REVIEW_REQUIRED / DEAD_LETTER / BLOCK_EXECUTION_FIELD
