## 6. GST／Origin Cell 最新 Founder 定義

D6 GST 的現行意圖是：以 8D 狀態分析求同存異，將可規則化之異改為可由共同生成關係表達，記錄同、異、同異關係及生成／還原規則，形成傳輸模組；目的端依相同規則生成式還原並驗證目標狀態。

明確排除：

- delta / patch（差分／補丁）
- compression（壓縮）
- file moving / sync（檔案搬運／同步）
- chunk（普通資料分塊）
- 把差異本身直接等同 transmitted payload（傳輸承載）
- 把 shared base + minimum delta（共同基座＋最小差量）當成永遠必要條件
