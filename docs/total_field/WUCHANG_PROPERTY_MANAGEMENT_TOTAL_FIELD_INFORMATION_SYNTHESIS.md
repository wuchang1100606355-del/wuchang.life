## Canonical Product Direction

This product should not be described as "just a property app".

It is:

```text
物業管理 + 管委會治理 + 住戶服務 + 商家服務 + 設備節點 + 證據封條 + 8D 身分封包 + AI 候選輸出 + 人類/總場驗證
```

The core value is not only managing records. The core value is proving who can do what, from which authority, with which evidence, before any property action becomes final.

## Optimization Principle

Every product feature should answer eight questions before implementation:

```text
D1 Intent: what property problem is being solved?
D2 State: current and target workflow state
D3 Coordinate: property/unit/role/device/time/resource refs
D4 Evidence: source, document, photo, hash, report, seal
D5 Execution: draft, candidate, approved action, or forbidden action
D6 Generative Transmission: how AI candidate output is transmitted without plaintext pollution
D7 Risk: privacy, legal, payment, access, member data, governance risk
D8 Envelope: verifier result and final boundary
```
