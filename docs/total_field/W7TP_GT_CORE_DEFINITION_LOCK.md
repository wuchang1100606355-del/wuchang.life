# W7TP 生成式傳輸核心定義鎖定

## 核心定義

生成式傳輸不是檔案本體傳輸、不是雲端密文同步、不是備份、不是下載解密還原。

生成式傳輸係將來源端之意圖、狀態、座標、證據、執行邊界、風險條件、權限、路由、TTL、雜湊、資源引用與重構條件封包化，使接收端無須取得完整原始本體，即可依本地查表、基底資源、生成規則引用與狀態場約束，生成或重現等價狀態、等價任務或等價效果，並由總場驗證閘門進行准駁、封印與阻擋。

## 附屬層界定

雲端密文同步只能列為冷資料 body reference 附屬層。

其角色是大型本體必要時的 cloud body reference，不得稱為生成式傳輸主體。

## 禁止誤稱

- 不得將 encrypted upload 稱為生成式傳輸主體。
- 不得將 decrypt restore 稱為完整生成式重構。
- 不得將 body storage 當核心發明。
- 不得以檔案搬運取代狀態場封包與重構條件。
