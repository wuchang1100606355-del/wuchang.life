## Layer Roles

1. LINE / chat / Odoo / browser
User-facing conversation entry.

2. AI candidate lane
Generates candidate answers, summaries, drafts, translations, and candidate packets.
AI is not authority.

3. 8D+7D state-field packet
Carries intent, state, coordinate, evidence, execution condition, technical boundary, risk, envelope, and functional state.

4. ADI 5D absolute index
Authoritative spatiotemporal state index.
It is not a generic database index, not a neural network, and not five JSON fields.

5. 7D functional state layer
Generates executable or equivalent functional state.

6. 8D authority envelope
Binds authority, TTL, nonce, hash, verifier, risk, and seal.

7. Total Field gate
Final authority.
Approves, rejects, HOLDs, seals, and blocks definition drift or pollution.

8. Human Response Renderer
Converts strict internal verifier result into natural human language.
General users must not see raw D1-D8 / verifier internals unless explicitly requested.
