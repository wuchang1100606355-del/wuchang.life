## 1. 核心定位

本智財防護之目的，不在壟斷 AI 模型本身，而在保護未來 AI 進入人類社會、社區治理、使用者主權、雲端候選、資料不可回推、執行驗證與公益落地時必經之技術道路。

## 2. 主幹道定義

AI 未來主幹道包含：

- 使用者主權 AI 控制
- 7D / 8D 意圖與狀態封包
- GCT 生成式通訊傳輸
- IFPC 意圖場封包建構
- 雲端 candidate_only 不可回推候選封包
- verifier-gated AI execution
- no-floating / lookup / deterministic runtime
- ADI causal sidecar ledger
- HMAC / prev_hash / trajectory verifier
- ΩGI 總場最終裁決

## 4. Claim Boundary

Allowed claims:

- 特定封包結構
- 特定傳輸邊界
- 特定驗證流程
- 特定使用者主權控制
- 特定不可回推雲端候選回傳
- 特定總場裁決 gate
- 特定 ADI sidecar event index
- 特定公益社區 AI 作業系統治理流程

Forbidden claims:

- 不得宣稱擁有所有 AI。
- 不得宣稱任何 AI 治理皆屬本發明。
- 不得宣稱相同效果即等同侵權。
- 不得宣稱 ADI 已是 production DB engine。
- 不得宣稱幸福幣已具金融支付或法幣替代地位。
- 不得揭露 H64-TD codebook / mapping / table / rules。
