# 申請專利範圍 V4

1. 一種基於正8維治理架構之主權式人工智慧意圖控制方法，由一個或多個處理器執行，包含：

建立一正8維治理資料結構，該正8維治理資料結構包含意圖場、狀態場、座標場、證據場、執行場、主權隱私場、生成式傳輸與資源路由場及紅隊防繞告警禁錮場；

藉由該意圖場定義任務主體、任務目標及任務邊界；

藉由該狀態場記錄真實狀態、處理進度、阻塞點及通過狀態；

藉由該座標場記錄人、事、時、地、權限及資源位置；

藉由該證據場記錄雜湊、清單宣告檔、帳本、報告路徑及驗證紀錄；

藉由該執行場記錄實際執行內容、資料寫入狀態、部署狀態、服務重啟狀態及發布狀態；

藉由該主權隱私場將會員明文或敏感資料轉換為會員參照、角色權杖、屬性證明或 key_ref，使候選人工智慧運算不得直接取得該會員明文或敏感資料；

藉由該生成式傳輸與資源路由場，將任務狀態轉換為封包參照、清單宣告檔、狀態差分、拓樸約束、資源約束、治理約束及驗證需求之一個或多個封包化狀態材料，並以分段式、參照式或差分式傳輸該封包化狀態材料至本地模型、邊緣節點、路由器節點、行動裝置節點、POS節點、雲端候選運算節點或資料保管節點；

使該等分散節點於不合併其實體權限之情況下，被治理為一邏輯節點整體；

由候選人工智慧運算依該封包化狀態材料產生候選輸出、候選狀態差分、候選行動或重構提示；

藉由本地重構與驗證器根據本地原始狀態、八維狀態封包、該候選狀態差分及該重構提示完成狀態重構與驗證；

藉由該紅隊防繞告警禁錮場偵測該候選處理流程是否偏離既定任務目標、是否重複研究、是否重新定義系統、是否未朝指定交付成果推進，或是否要求危險操作候選；

僅於該本地重構與驗證器及該紅隊防繞告警禁錮場判定通過時，允許執行轉接器以最小權限執行該候選行動。

2. 如請求項1所述之方法，其中該意圖場、狀態場、座標場、證據場及執行場形成五合一核心治理閉環。

3. 如請求項1所述之方法，其中該生成式傳輸與資源路由場包含一硬體網路邊界節點，該硬體網路邊界節點為路由器節點，並用以作為 LAN、WAN、VPN、防火牆、DNS、封包通道、硬體通道或本地/邊緣/雲端資源路由之邊界座標。

4. 如請求項1所述之方法，其中該生成式傳輸與資源路由場使複數個分散節點於不合併其實體權限之情況下，被治理為一邏輯節點整體；其中該邏輯節點整體係由封包參照、清單宣告檔、狀態差分、資源路由資料、驗證收據及本地重構結果形成。

5. 如請求項1所述之方法，其中該紅隊防繞告警禁錮場於偵測到繞路狀態、重複研究、重新定義、權限越界、明文外洩風險、資料庫寫入風險、部署風險、服務重啟風險、正式發布風險或未經授權之路由器設定變更候選時，將該候選流程標示為 HOLD、DENY、SANDBOX_ONLY、HUMAN_REVIEW_REQUIRED、DEAD_LETTER、ROLLBACK_REQUIRED 或 BLOCK_EXECUTION_FIELD。

6. 如請求項1所述之方法，其中該候選人工智慧運算不得於未經本地重構與驗證器通過前執行資料庫寫入、付款、正式下單、服務重啟、部署、正式發布、路由器設定修改或會員明文讀取。

7. 如請求項1所述之方法，其中該座標場保存智財、專利、效能數據或技能管理之索引位置，該證據場保存其雜湊、清單宣告檔、報告路徑及驗證紀錄，而該紅隊防繞告警禁錮場不管理智財、專利、財務、資源、效能數據或技能管理。
