# W7TP Indexer Server Dry-Run Record

Status: `record-template`

This is a dry-run record template for the future `wuchang_indexer_oneshot`
server preparation workflow. It is not evidence that deployment occurred, and
it is not evidence that a container was started.

## Recording Rule

- The template must be filled in and reviewed by a human operator.
- The record captures artifact checks, static linter outcomes, hashes, and a summary only.
- Execution flags remain `false` for this template.
- A completed record remains subject to a human approval decision.

## Boundary

- No server execution is authorized by this document.
- No secret, raw PII, formal database write, router access, or remote access is authorized.
- A real server execution requires a separate explicitly approved task.
