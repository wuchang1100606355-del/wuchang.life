# M31A: XiaoJ Converged Governance Architecture

Status: `plan_only`

## Summary

小J不是單一 LLM，而是五常智慧雲 / W7TP 的本地治理意圖場。  
本收斂架構整合東方AI、道德自限、雙腦合一、7D/5D 封包、VSCode/Ultra 作業模式、行動端小J、團體會員算力支援、來賓網路喚醒、會員個資封存、三金鑰USB分權、one-way privacy gate、設備遺失停權轉移與專利證據鏈。

## Core Principles

- 東方AI不是玄學，而是可工程化的語義、狀態、風險、路由與治理模型。
- 前腦負責思想、意圖、人格、價值脈絡、公益使命與創意候選。
- 後腦負責行動準則、硬牆、linter、policy gate、dead-letter、audit 與 commit 邊界。
- 前腦可在內部思想與創意候選階段無柵欄發散，但不得越過後腦硬牆。
- 紅隊除錯不只是封鎖器，也是雙腦傳輸架構的優化器。
- 可以說不知道；寧願不知道也不可跳過驗證；寧願延遲也要驗證。
- 預測可以加速準備，但不可冒充驗證結果。
- 來賓網路只能喚醒，不可證明身份。
- 團體會員設備可提供算力支援，但不得取得會員資料主權。
- 會員個資僅於入會/註冊時最小必要收取，註冊後物理或加密封存。
- 系統可接收個資做核驗，但不得回顯原始個資。
- 三金鑰USB分權必須做到連創辦人/總幹事也不能單獨查看原始個資。
- 設備遺失、停權、轉移、新設備綁定必須本人或受委託親屬提出身分證明並經人工審查。

## Evidence Chain

Every governed development action should preserve task id, packet hash, commit hash, linter output, validation summary, focused git status, compact task card, and patent evidence candidate marker.
