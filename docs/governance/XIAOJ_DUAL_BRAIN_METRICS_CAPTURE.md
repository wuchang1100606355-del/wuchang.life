# M32C: XiaoJ Dual-Brain Metrics Capture

Status: `plan_only`

This contract defines metrics capture for XiaoJ dual-brain governance.

The front brain measures intent, value-context preservation, creativity, and harmlessness self-checks. The rear brain measures policy hits, guardrail hits, dead-letter events, validation pass/fail, and human-review triggers.

This stage captures metrics only. It does not start models, call cloud APIs, read secrets, read raw member PII, SSH, start containers, restart services, or perform formal writes.
