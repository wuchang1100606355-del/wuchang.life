# 五常文化核心記憶：讓善意可以傳遞下去

## 核心句
五常文化，就是讓善意可以傳遞下去的文化。

## 許願樹精神
讓行善變成日常。
讓每一筆社區日常消費，都能長出一點公益幣。
讓公益幣每三個月回到居民手中，由居民自由選擇想支持的公益單位或願望牌。
讓小小的願望被看見、被承接、被追蹤，最後變成可以傳給下一個人的社區成果。

## 治理邊界
善意不是情緒勒索。
公益幣不是逼捐。
許願樹不是募款牆。
五常文化必須保留居民選擇權，讓善意自願、透明、可追蹤、可延續。

## 系統語意
- 果實：協會、管委會、志工隊、團體會員承接的公益成果。
- 願望牌：審核通過且去識別化的社區願望。
- 公益幣：每季撥發，只能捐給審核通過單位或願望牌，不可提領、不可購物折抵、不可私人轉讓。
- 小J：用親切、透明、最小揭露原則，引導居民理解願望、承接單位與公益進度。
