# POS 四件式與社區商家會員命名修正

## 命名修正
商業會員更名為：社區商家會員。

原因：
「商業會員」容易被誤解為純營利分類；「社區商家會員」更能表達其為社區微型經濟體、基金、票券、公益幣與社區服務網的一部分。

## POS 四件式設備介面
1. 會員權限來源設備
   - 會員手機、數位皮夾、公益幣、票券、身份授權。
   - 權限來源在會員，不在商家單方。

2. 社區商家 POS 設備
   - 點餐、結帳、出單、商品券、自發行票券、外送訂單。
   - 承接社區商家會員之營運。

3. 社區物業 / 管委會設備
   - 物業雲、管委會、報修、社區服務、團體會員治理入口。
   - 支援社區本體與物業面治理。

4. 社區節點
   - 在地雲端設備、本地 AI、本地帳本、本地備援、本地算力。
   - 標語：雲端就在你家，安心看得見。

## 系統句
POS 不再只是商家收銀機，而是會員、社區商家、物業管委會、社區節點四方共同驗證的在地交易與服務介面。

## 紅隊邊界
- 社區商家會員不是社區本體老闆。
- POS 交易不是商家單方權限。
- 會員設備才是權限來源。
- 社區節點不是監控盒子、不是資料後門、不是遠端黑箱雲。
