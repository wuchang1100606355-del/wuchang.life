# W7TP State World Atlas v1.1

## Purpose
This document upgrades W7TP from Field Atlas terminology into State World / Sub-Universe terminology while preserving Field Atlas compatibility.

## Definitions
- Field: bounded functional domain.
- State World: governed integrated system world composed of multiple fields.
- Sub-Universe: coupled multi-field execution domain.
- Future: simulation/projection only, not certainty.

8. Earthly Branches: runtime rhythm tensor.
9. Jiazi: time-state tensor.

## Time Authority

## Temporal Model
- Past Reconstruction: evidence, logs, snapshots, rollback.
- Present Observation: runtime, services, docker, memory, gateway.
