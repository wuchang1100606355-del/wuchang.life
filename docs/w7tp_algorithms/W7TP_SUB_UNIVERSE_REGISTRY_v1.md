# W7TP Sub-Universe Registry v1

## Purpose
This document defines W7TP Sub-Universes as coupled multi-field execution domains inside the W7TP State World.

## Engineering Definition
A Sub-Universe is not a metaphysical claim. It is an engineering classification for a bounded subsystem composed of multiple fields, with its own identity context, time authority, memory lifecycle, governance boundary, evidence chain, compute lane, and development path.

## Initial Sub-Universes
1. Local XiaoJ Core
2. Commerce Odoo POS
3. Public Interest Service
4. Dual Cloud Compute
5. IP Evidence World
6. Media Avatar World

## Governance Rules
- No Sub-Universe bypasses D6 governance.
- API keys remain isolated inside gateway runtime.
- Personal data does not flow across domains.
- Compute and redacted state may flow through governed packet lanes.
- Local device time remains the primary authority.
