# 公益學術研究資料治理政策

版本：2026-05-11  
適用主體：新北市三重區五常社區發展協會  
資訊負責人：江政隆，本會授權之總幹事  
適用用途：公益、社區發展、學術研究、社區產業發展、服務改善  

## 核心定位

本會得基於公益與學術研究用途，建立個資及行為資訊之收集、記錄、研究使用制度。

但公益學術用途不等於無限制使用。

所有蒐集、處理、利用應符合：

- 特定目的
- 最小必要
- 告知 / 同意 / 合法例外
- 去識別化或假名化優先
- 權限分窗
- D 磁碟守門或受控研究資料區
- audit / SHA256 baseline
- 研究計畫或倫理審查判斷
- 不得送外部 AI 明文
- 不得進無敏唯讀雲端

## 可適用目的類別

依個人資料保護法特定目的分類，本系統可評估對應：

| 代號 | 類別 | 本系統可能用途 |
|---|---|---|
| 052 | 法人或團體對會員名冊之內部管理 | 本會會員、幹部、組織治理 |
| 057 | 社會行政 | 社區發展與協會治理 |
| 058 | 社會服務或社會工作 | 社區服務、福利、公益服務 |
| 157 | 調查、統計與研究分析 | 社區行為資料統計與服務改善 |
| 159 | 學術研究 | 公益學術研究、社區產業研究 |
| 181 | 組織章程所定業務 | 本會章程與會員大會通過之專案 |

實際使用前應由資訊負責人確認特定目的與資料類別。

## 行為資訊定義

行為資訊可能包含：

- 系統操作紀錄
- 服務使用紀錄
- 設備互動紀錄
- POS / Odoo 草稿流程紀錄
- 會員設備遺失或變更事件
- 社區服務參與紀錄
- 語音或瀏覽器介面事件摘要
- 算力協作事件

行為資訊若可直接或間接識別個人，即視為受保護資訊。

## 研究資料分級

| 類型 | 位置 | 允許用途 | 上雲 |
|---|---|---|---|
| 去識別統計 | 組織唯讀雲端 / Linux | 公益展示、研究摘要 | YES |
| 假名化研究資料 | Linux / D 研究區 | 研究分析 | NO plaintext cloud |
| 明文個資研究資料 | D 磁碟守門區 | 僅必要研究與審查 | NO |
| 行為事件 hash | Linux audit | 系統改善、稽核 | YES if non-identifying |
| 原始行為明文 | D 或 C 受控區 | 僅必要、短期 | NO |

## 研究前必要文件

正式進入研究使用前，至少應建立：

- 研究目的說明
- 資料類別清單
- 當事人告知或同意方式
- 是否需倫理審查或倫理審查豁免判斷
- 去識別化方法
- 資料保存期限
- 存取人員名單
- 風險與公益利益評估
- audit / SHA256 / rollback 或刪除流程

## AI 使用邊界

AI 可協助：

- 建立研究 schema
- 建立去識別化流程
- 產生統計分析程式
- 產生匿名化報告
- 建立資料品質檢查
- 建立倫理審查輔助文件

AI 不可：

- 讀取會員明文
- 輸出會員明文
- 將個資或可識別行為資料送外部模型
- 以 raw behavior log 直接訓練或建立可逆 profile
- 將研究資料用於商業個人化推銷

## 開發期與正式營運期

開發期：

```text
使用幹部測試帳號、mock、schema、redacted fixture。
不使用正式會員明文資料。
```

正式營運期：

```text
研究資料使用須走本政策。
會員資訊庫若啟用，仍受 D 磁碟物理封存與開封規則約束。
```

## L3 Metric Hazard

以下一律封鎖：

- 以公益學術名義無限制蒐集個資
- 未告知或無合法依據蒐集可識別行為資訊
- 將明文個資或可識別行為資料上傳雲端
- 將個資送外部 AI
- 未去識別化即公開研究資料
- 將研究資料用於個人利益或商業濫用
- 刪除研究 audit / SHA256 / 同意或審查紀錄

## 最終原則

```text
公益學術用途可以成立，但必須被治理。
研究可以使用資料，但資料不可失控。
可公開的是去識別成果，不是個人明文。
Taiji Hub 應讓社區研究更安全、更可稽核，而不是讓個資更容易外流。
```
