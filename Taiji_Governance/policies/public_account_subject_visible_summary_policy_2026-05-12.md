# 公益帳戶公開：數據科目可見、摘要可見、明細不可見

版本：2026-05-12  
適用：Odoo / ADI / 公益帳戶 / 組織雲端公開看板  

## 核心規則

公益帳戶公開方式為：

```text
數據科目可見。
摘要可見。
明細不可見。
```

公開的目的，是讓居民、會員、主管機關、合作方與社會可查核公益流向，而不是公開個人、商家或單筆敏感明細。

## 可見內容

公益帳戶公開看板可見：

- 會計科目名稱
- 公益收入分類
- 公益支出分類
- 分類總額
- 月/季/年趨勢
- 基金池留存總額
- 社區服務成果摘要
- ESG 指標摘要
- 社區向量資訊授權收入摘要
- 資料版本與 SHA256
- audit 摘要

## 不可見內容

公益帳戶公開看板不可見：

- 單筆憑證影像
- 個別會員姓名
- 個別服務紀錄
- 個別 POS 交易紀錄
- 商家營業機密
- 供應商未公開價格
- 未公開合約
- 管委會敏感會議細節
- secret / token / key
- 可逆識別欄位

## 公開層級

| 層級 | 可見性 | 範例 |
|---|---|---|
| 科目層 | 可見 | 公益服務收入、系統維運支出、基金池留存 |
| 摘要層 | 可見 | 本月收入總額、本季公益支出總額 |
| 趨勢層 | 可見 | 月趨勢、季趨勢、年度比較 |
| 明細層 | 不可見 | 單筆交易、單一付款對象、單一會員紀錄 |
| 憑證層 | 權限可見 | 會計/審查者可查，公開端不可見 |

## ADI 欄位

```json
{
  "public_account_visibility": "subject_and_summary_only",
  "subject_visible": true,

  "detail_visible": false,
  "voucher_visible": false,
  "personal_data_visible": false,
  "business_secret_visible": false,
  "sha256_visible": true

```

## L3 Metric Hazard

以下一律封鎖：

- 公益公開頁顯示單筆個人紀錄
- 公益公開頁顯示商家敏感明細
- 公益公開頁顯示憑證影像或帳戶資訊
- 摘要資料可逆推出個人或商家
- 為了公開透明而犧牲個資與營業機密

## 最終原則

```text
公開的是科目與摘要。
保護的是明細與人。
公益透明不等於資料裸奔。
```
