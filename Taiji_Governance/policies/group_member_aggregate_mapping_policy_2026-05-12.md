# 團體會員個別總量映射與統計公開政策

版本：2026-05-12  
適用：本會總資料庫、團體會員資料、公益帳戶、社區向量資訊、Odoo / ADI  

## 核心規則

團體會員之個別資訊不得公開。

公開端僅可見：

```text
映射公式
欄位定義
聚合方法
最後統計數據
```

個別會員行為資訊可匯入本會總量計算項目，但公開端、AI 上下文與買方資料產品不得看見個別數字或計算過程。

正式規則：

```text
只見公式。
不見個別數字。
只見結果。
不見過程。
```

不可見：

```text
個別團體會員資料
個別商家營業明細
個別服務紀錄
個別交易紀錄
個別會員或團體可識別資訊
```

## 總資料庫定位

本會總資料庫為權限可見、可稽核、不可公開明細之治理資料庫。

本會總資料庫可用於：

- 統計映射
- 公益帳戶摘要
- 社區向量資訊產製
- ESG 指標計算
- Odoo / ADI 帳務分窗
- 社區產業分析

不得用於：

- 公開個別資訊
- 無權限查詢個別資料
- 外部 AI 明文分析
- 可逆識別之資料產品

## 可公開內容

公開端可見：

| 類型 | 範例 |
|---|---|
| 公式 | `公益服務量 = Σ(服務事件 * 度規權重)` |
| 欄位定義 | 服務次數、服務類別、時間窗、區域 |
| 聚合方法 | 月統計、季統計、里別統計、產業別統計 |
| 最後統計數據 | 總量、平均、趨勢、比例 |
| 版本資訊 | dataset_version、sha256、產製時間 |

## 不可公開內容

公開端不可見：

- 團體會員名稱與其個別數值對應
- 商家個別營業額
- 單一會員或商家的服務紀錄
- 單筆 POS/Odoo 交易
- 明細憑證
- 可逆推個體的細分統計
- 小樣本可識別統計

## 小樣本保護

若統計分組樣本數過小，可能逆推出個別團體或個人，應：

- 合併分組
- 延後公開
- 只公開更高層級統計
- 或標記為不可公開

建議門檻：

```text
group_count < 5 → 不公開細分統計
event_count < 10 → 不公開細分統計
single_dominant_entity > 70% → 需合併或遮蔽
```

## 社區向量資訊關係

社區向量資訊資料產品只可使用：

- 聚合總量
- 去識別向量
- 不可逆統計
- ESG 指標
- 公益服務趨勢

不可使用：

- 個別團體會員明細
- 可逆會員標籤
- 可識別商家明細
- 小樣本可逆統計

## L3 Metric Hazard

以下一律封鎖：

- 公開團體會員個別資訊
- 公開個別會員/商家與數據對應
- 以公式公開之名，實際讓人逆推出個體
- 小樣本統計造成識別風險
- 將本會總資料庫明細交給買方
- 將個別資訊送外部 AI

## 最終原則

```text
公開公式，不公開個體。
公開總量，不公開明細。
公開統計，不公開可識別資料。
本會總資料庫可稽核，但個別資訊不可見。
```
