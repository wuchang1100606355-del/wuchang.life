# 無敏五維度規向量資料產品授權政策

版本：2026-05-11  
適用主體：新北市三重區五常社區發展協會  
用途：公益學術研究、社區產業、ESG 指標、社區治理資料產品  

## 核心修正

本系統不以「販售個資」為目的。

本系統可評估建立：

```text
無敏、不可逆去識別、聚合化、公益學術與 ESG 用途之五維度規向量資料產品授權制度。
```

建議正式用語：

- 資料產品授權
- 去識別統計資料授權
- 社區 ESG 指標資料授權
- 五維度規向量指標資料庫授權
- 公益學術研究資料產品授權

避免使用：

- 會員行為資料販售
- 個資販售
- 可識別行為側寫販售
- 會員資料庫販售

## 可授權資料範圍

可授權者必須同時符合：

- 無敏
- 不含會員明文
- 不含可逆識別符
- 不含 secret
- 不含商家營業機密
- 不含管委會敏感會議資訊
- 已聚合或去識別化
- 無法直接或間接識別特定個人
- 有公益/學術/ESG 目的
- 有 audit / SHA256 / 版本封存

## 不可授權資料範圍

以下不得作為資料產品授權：

- 會員名冊
- 會員明文個資
- 個別會員行為紀錄
- 可逆推出個人的 hash / tensor / vector label
- D 磁碟會員資訊庫
- 原始 POS/Odoo 個別交易明細
- 商家營業機密
- 管委會敏感會議資訊
- secret / token / key / credential
- 可被買方用於個人化廣告、信用評分、歧視性決策或監控之資料

## ESG 指標授權

巨頭或合作方購買本會資料產品時，可被授權使用：

- 社區公益參與指標
- 社區服務能量指標
- 社區產業永續指標
- 數位包容指標
- 社區碳減量或資源效率指標
- 非識別化服務觸達統計
- 公益算力貢獻統計

但不得宣稱：

- 已取得會員個別行為資料
- 可識別會員或居民
- 可用於個人評分
- 可用於商業個人化追蹤
- 可替代正式 ESG 查證或第三方認證

## 授權條款必備

資料產品授權契約需包含：

- 資料為去識別 / 聚合 / 無敏資料
- 禁止再識別
- 禁止與外部資料交叉比對回推個人
- 禁止轉售原始資料
- 禁止用於歧視、監控、信用或保險個人決策
- 僅限公益、學術、ESG、社區產業研究用途
- 保留本會審計權
- 保留撤銷授權權
- 買方資料安全義務
- ESG 使用聲明需真實、可查核、不得漂綠

## Five-Metric 判斷

每次資料產品授權需建立：

```json
{
  "intent_metric": "public_interest_esg_research_data_license",
  "resource_metric": "deidentified_vector_dataset",
  "time_metric": "licensed_version_window",
  "authority_metric": "association_authorized_data_product",
  "topology_metric": "org_readonly_cloud_or_contract_delivery",
  "personal_data_included": false,
  "reidentification_risk": "controlled",
  "audit_required": true,
  "contract_required": true
}
```

## L3 Metric Hazard

以下一律封鎖：

- 販售會員明文個資
- 販售個別會員行為資料
- 提供可逆識別資料
- 買方要求再識別
- 買方將資料用於個人化追蹤、信用、保險、招聘或歧視性決策
- 將 D 磁碟會員庫轉成資料商品
- 將外部 AI 明文處理作為資料產品製程
- ESG 宣稱不可查證或具有漂綠風險

## 最終原則

```text
可授權的是無敏、去識別、聚合、公益與 ESG 指標資料。
不可販售的是會員個資、個別行為、可逆識別或機密資料。
巨頭可以買社區公益與 ESG 指標，不可以買居民可識別資料。
資料產品收入須回到社區產業與公益基金池治理。
```
