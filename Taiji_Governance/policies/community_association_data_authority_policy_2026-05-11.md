## 核心聲明

本專案唯一劇本為：

```text
社區發展協會經會員大會通過之社區產業發展專案
```

因此，專案內涉及會員、社區產業、商家合作、管委會會議、業務服務、POS/Odoo 場景之資料，不應被描述為「個別團體會員私自管轄」。

本會對相關資訊具有保護、治理、最小必要使用、權限分窗、audit、封存與存取審查之責任。

## 權限來源

| 層級 | 說明 |

| 會員大會 | 專案最高授權來源 |
| 社區發展協會 | 公益治理與資料保護責任主體 |
| 社區產業發展專案 | 本系統唯一正式劇本 |
| 專案維運者 / 開發者 | 依授權進行系統開發、維運、資料保護與技術落地 |
| Taiji Runtime | 依 Five-Metric / Gateway / Audit / Human Decision 執行治理 |

## 資料權限語意修正

應使用：

```text
本會受保護資訊
協會治理資料
社區產業專案資料
會員大會授權專案資料
受權限分窗保護之會員相關資料
```

避免使用：

```text
個別團體會員自行管轄資料
個人任意持有會員資料
無治理邊界的會員進度
可由 AI 任意讀寫的會員資料
```

## 保護責任

本會具有資訊保護責任，不等於資料可任意流通。

任何涉及會員相關資料、商家營業資料、管委會資訊、服務歷程、POS/Odoo 場景資料之處理，必須符合：

- 會員大會通過之專案目的
- 公益度規
- 最小必要使用
- 權限分窗
- audit 留痕
- 文件版本封存
- SHA256 baseline
- rollback reference
- 不任意上雲
- 不任意外部 AI 明文處理

## 儲存邊界

| 位置 | 資料定位 | 規則 |
|---|---|---|
| Linux 子系統 | 開發 / runtime / 測試 | 可處理受控開發資料，但不得輸出 secret 或任意外送個資 |
| C 磁碟個別需求資料夾 | 經常讀寫之場景資料 | 可存團體會員、商家營業、管委會資訊，但需權限分窗 |
| 組織共用雲端 | 無敏、唯讀、全設備可用 | 僅放去敏文件、架構、schema、無敏 artifact |
| D 磁碟 / 記憶卡 | 高權限、特殊用途、熱資訊 | 需本人審查、公益度規、audit、SHA256 |

## 開發期會員資料規則修正

先前「不保存會員個別進度」之規則仍有效，但其意義修正如下：

```text
不建立 AI 開發期的個人化會員追蹤資料庫。
不將會員資料轉成可任意 replay 的 Runtime 記憶。
不將會員個資或服務歷程送往無敏雲端或外部 AI。
```

並不否認：

```text
本會在會員大會通過之專案目的內，對會員相關資訊具有保護與治理責任。
```

## L3 Metric Hazard

以下一律封鎖：

- 將本會受保護會員資料視為個人私有資料任意處理
- 將本會受保護資訊直接同步到無敏雲端
- 將會員相關明文資料送外部 AI
- 將商家營業資料或管委會敏感資訊未去敏上雲
- AI 以自然語言直接改寫 production Odoo/POS 會員或營業資料
- 未經公益度規與權限分窗，將協會資料轉為私人利益
- 刪除 audit、SHA256 baseline、rollback 或會員大會授權脈絡

## 最終原則

```text
本會不是資料濫用者。
本會是經會員大會授權之社區產業發展專案治理者。
Taiji Hub 必須協助本會保護資訊、降低外洩、維持公益目的、保留稽核與可回滾治理證據。
```
