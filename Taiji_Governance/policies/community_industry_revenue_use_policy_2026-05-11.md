# 社區產業收入使用權限政策

版本：2026-05-11  
適用主體：新北市三重區五常社區發展協會  
專案定位：會員大會通過之社區產業發展專案  
資訊負責人：江政隆，本會授權之總幹事  

## 核心原則

本會基於會員大會通過之社區產業發展專案，得建立社區產業收入之收支、使用、留存、分配與再投入治理制度。

社區產業收入之使用權限應服務：

- 公益目的
- 社區服務
- 社區產業永續
- 數位發展基金池
- 系統維運
- 合理勞務與智慧貢獻量化
- 社區居民與公共利益

不得服務：

- 私人資產挪用
- 未授權私人分配
- 公益資源轉私人利益
- 未經會計分窗之混帳
- 無 audit 之支出

## 收入來源

社區產業收入可能包含：

- POS / 點餐 / 社區商店收入
- 社區服務費
- 社區產業合作收入
- 技術服務收入
- 公益服務點數或貢獻制度
- 社區數位發展基金池收入
- 經會員大會或本會授權之其他收入

## 使用項目

社區產業收入可用於：

| 類別 | 用途 |
|---|---|
| 系統維運 | Odoo、POS、Gateway、雲端/本機資源、備份、資安 |
| 公益服務 | 社區服務、照顧、公益活動、弱勢支持 |
| 社區產業 | 商品、設備、場地、教育、行銷、服務流程 |
| 勞務補償 | 社工、店務、技術、管理、志工合理補貼 |
| 智慧貢獻 | 架構設計、系統開發、資料治理、教育訓練 |
| 風險準備 | 資安、維修、事故、合規、保險或應急 |
| 基金池 | 社區數位發展與永續運作 |

## 財務分窗

收入使用必須分窗：

```text
公益用途
社區產業成本
系統維運成本
合理勞務補償
智慧貢獻量化
風險準備
基金池留存
```

不得將公益基金池直接轉為私人帳戶收益。

若涉及勞務或智慧貢獻，應以：

- 服務契約
- 支出憑證
- 會計科目
- 本會授權
- 合理市場或內部估值
- audit record

進行處理。

## Odoo 對應

建議 Odoo 建立：

- 社區產業收入帳
- 公益基金池帳
- 系統維運成本中心
- 勞務補償成本中心
- 智慧貢獻成本中心
- 社區服務專案帳
- POS / Odoo / Google / Runtime 維運支出分類

## 五維度規收入使用判斷

每筆收入使用需映射：

```json
{
  "intent_metric": "community_industry_revenue_use",
  "resource_metric": "fund_pool_or_operating_revenue",
  "time_metric": "accounting_period",
  "authority_metric": "association_authorized_financial_window",
  "topology_metric": "odoo_accounting_and_audit_runtime",
  "public_interest_metric": "aligned",
  "private_gain_risk": "checked",
  "audit_required": true
}
```

## L3 Metric Hazard

以下一律封鎖：

- 公益基金池直接轉私人收益
- 未經授權使用社區產業收入
- 未留憑證與 audit 的支出
- 將私人商業收入與本會收入混帳
- 將商家營業資料未分窗進本會帳
- 未經會計分窗認列勞務或智慧貢獻
- AI 自動核准付款、轉帳、退款或補償

## 開發期與正式營運期

開發期：

```text
可建立 schema、Odoo 模型、POS 草稿、會計分窗設計。
不得自動執行付款或正式入帳。
```

正式營運期：

```text
需會計制度、授權決議、憑證、audit、Odoo 帳務與人類確認。
```

## 最終原則

```text
社區產業收入可用於公益與永續。
公益不是要求人白工。
勞務與智慧貢獻可以合理量化。
但所有收入使用必須分窗、合規、可稽核，不得混同私人利益。
```
