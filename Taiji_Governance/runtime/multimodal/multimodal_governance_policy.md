# Multimodal Governance Policy

## Allowed

- redacted image summary
- non-sensitive device status
- POS draft UI metadata
- Odoo non-sensitive state
- hash references

## Blocked

- raw customer personal data
- payment-sensitive data
- service account material
- OAuth/session content
- private Gmail content
- raw Odoo member plaintext

High-cost multimodal generation requires Resource Metric justification.
