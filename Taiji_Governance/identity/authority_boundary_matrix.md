# Authority Boundary Matrix

| Action | Runtime Owner | Architect | Community Governor | Sponsor | Operator | Private Commercial | Community Industry |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Define metric law | propose/approve | propose | advise public-interest | no | no | no | advise |
| Architecture proposal | approve | yes | advise | advise | advise | no | advise |
| Read-only inspection | yes | yes | scoped | scoped | yes | scoped private | scoped community |
| Local patch | approve | yes | no | no | approved only | private scope only | community scope only |
| Deployment approval | human decision required | propose only | public-interest approve | no | execute approved only | private scope only | community scope only |
| Rollback | approve | propose | if public-interest affected | no | execute approved | private scope | community scope |
| Payment execution | human decision + accounting | no | policy approve only | no | no | private accounting only | accounting window only |
| Credential issuance | human decision required | no | no | no | no | no | no |
| Public asset transfer | blocked unless lawful governance process | no | governed process only | no | no | no | no |
| Deadbox restore | human decision if L2/L3 | propose | public-interest review | no | execute approved | no | no |

No column may unilaterally approve L3 actions.
