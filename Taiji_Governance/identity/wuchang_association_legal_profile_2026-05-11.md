## 系統治理定位

本組織為 Taiji Hub 目前社區治理與社區產業發展專案之主要公益治理主體。

本專案的正式劇本為：

```text
新北市三重區五常社區發展協會
經會員大會通過之社區產業發展專案
```

因此，Taiji Hub 中涉及社區治理、社區產業、Odoo、POS、業務服務、管委會應用、組織共用雲端與文件封存之規劃，應優先對齊本組織法定身分與主管機關邊界。

## 權限與責任邊界

本會對專案相關資訊具有保護、治理、最小必要使用與權限分窗責任。

此責任不代表：

- 可任意外送會員資料
- 可任意公開商家營業資料
- 可任意公開管委會敏感會議資訊
- 可任意由 AI 或自然語言直接修改 production Odoo/POS
- 可將公益治理資產轉為私人利益

此責任代表：

- 需建立合法授權脈絡
- 需建立資料分類
- 需建立權限分窗
- 需建立 audit / rollback / SHA256 baseline
- 需維持公益度規
- 需保護會員、商家、管委會與社區服務資料

## 雲端組織共用空間映射

雲端組織共用空間應使用無敏、唯讀、全設備可用原則。

可放：

- 組織法定身分摘要
- 無敏白皮書
- 架構圖
- schema
- 去敏治理文件
- 無敏 deploy manifest

不可放：

- 會員明文個資
- 會員個別服務歷程
- 商家營業機密
- 管委會敏感會議資訊
- secret / token / key / service account JSON

## L3 Metric Hazard

以下行為一律封鎖：

- 將本會受保護資訊視為個人私用資料
- 將會員明文資料放入無敏雲端
- 將商家營業資料未去敏公開
- 將管委會敏感會議資訊未去敏公開
- 刪除會員大會授權脈絡
- 刪除主管機關與法定組織邊界
- 繞過 Gateway / Five Metric / Audit / Rollback 直接操作 production
