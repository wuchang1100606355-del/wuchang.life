# Audit Scope Matrix

| Identity | Audit required | Monthly/public report candidate |
| --- | --- | --- |
| Runtime Owner | policy changes, baseline changes | governance summary |
| System Architect | architecture proposals, deployment plans | technical progress |
| Community Governor | public-interest goals/use cases | public-interest summary |
| Technology Sponsor | donation/lending/transfer | sponsor/support report |
| Runtime Operator | maintenance, rollback, health checks | operations report |
| Private Commercial Operator | private/commercial separation events | private scope only |
| Community Industry Operator | service node/fund-pool records | community industry report |
