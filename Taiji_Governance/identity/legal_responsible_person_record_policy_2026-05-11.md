# 法定組織負責人明文紀載政策

版本：2026-05-11  
適用主體：新北市三重區五常社區發展協會  
用途：組織治理、Odoo 主體、Google Workspace 組織資料、文件封存與主管機關對齊  

## 核心規則

依法應明文紀載之組織識別欄位，不適用一般「不得保存明文個資」之開發期禁止規則。

原因：

```text
組織負責人屬於法定組織識別與治理責任欄位。
依法登記與治理文件中需明文紀載。
```

但此明文紀載仍受以下限制：

- 僅限法定必要欄位
- 僅限組織治理、主管機關、Odoo 主體、文件封存與授權邊界使用
- 不得作為 AI 任意記憶
- 不得送入無治理外部 AI
- 不得與會員個別進度混用
- 不得被用於私人商業濫用
- 需保留 audit 與文件版本

| 法定組織負責人 | YES | 依法需明文紀載 |

## 不得擴張

法定負責人明文紀載，不代表以下資料可任意明文保存或上雲：

- 會員個別進度
- 會員服務歷程
- 商家營業機密
- 管委會敏感會議資訊
- secret / token / key / service account JSON
- 私人身分證字號、住址、電話等非必要欄位

## 儲存位置

| 位置 | 是否可存 |
|---|---|
| Linux governance repo | YES |
| 組織共用雲端無敏唯讀區 | CONDITIONAL，限法定組織簡介與公開治理文件 |
| C 磁碟場景資料 | YES，若屬作業文件 |
| D 磁碟高權限區 | YES，若屬正式封存或主管機關文件 |

## Runtime Rule

任何使用法定組織負責人欄位的 runtime packet 必須標記：

```json
{
  "data_classification": "statutory_organization_identity",
  "plaintext_allowed": true,
  "purpose": "legal_governance_record",
  "audit_required": true,
  "member_progress": false,
  "secret_material": false
}
```

## L3 Block

以下一律封鎖：

- 將法定負責人欄位擴張成私人追蹤資料
- 將法定負責人欄位與會員個別進度混用
- 將非必要私人資料加入法定組織 profile
- 使用法定負責人欄位繞過 Gateway / Audit / Five Metric
- 刪除法定授權脈絡與文件版本
