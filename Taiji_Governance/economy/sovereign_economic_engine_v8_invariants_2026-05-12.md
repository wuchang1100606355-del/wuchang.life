# 五常主權系統 V8.0 原意保全不變式

日期：2026-05-12  
狀態：設計精神保全；非金流執行；非法律/會計正式意見  

## 不可削弱的核心精神

### 1. `0 EPS -> ESG`

`0 EPS` 不是沒有獲利能力，而是不以私人股東利潤最大化為終局。系統所創造的商業紅利、技術授權收入、社區服務收入與成本節省，應在合規、會計與人類決策下，轉化為 ESG 影響力資本。

### 2. 公益不是乞求

公益應被視為可設計、可量測、可查核、可再投資、可長期維持的能力。系統目標不是依賴單點補助，而是建立社區自我造血與自我保護能力。

### 3. Odoo 是社區主權經濟總控場景

Odoo / Wuchang OS 承擔多公司、多帳冊、多網域、多模組的場景主系統角色：

- 主公司：新北市三重區五常社區發展協會。
- 分支/平台：物業協力平台、商業協力平台、聊國咖啡仁義店。
- 協力/技術轉移節點：聊國咖啡重新總店 / 上品食品行。

### 4. 聊國咖啡是實體示範與商業驗證節點

聊國咖啡相關節點承擔 POS 示範、菜單複製、商業模式驗證、前期支援與技術轉移功能。但它不得與協會公益資產或會計主體混同。

### 5. 社區數位發展資本池

系統應在 Odoo 會計/分析帳戶中建立社區數位發展資本池，用於承接合規收入、分流、準備金、票券池、算力建設、專勤隊與許願樹防護網。

### 6. 幸福幣 / 商家票券池是主權微循環

幸福幣與商家票券生產額度的核心不是金融投機，而是：

- 社區微勞動回饋。
- 在地消費二次循環。
- 商家獲客成本內部化。
- 消費者公益參與感。
- 協會基金池與服務能力累積。

### 7. 社區專勤隊是弱勢與中高齡賦能機制

外送不只是物流。社區專勤隊應被設計為健康訪視、銀髮賦能、弱勢微勞動、新住民協作與在地關懷的服務網路。

### 8. 算力主權是公益基礎設施

邊緣算力、五維度規、無明文上下文、度規匝道器與本地 AI 不只是工程工具，而是讓社區降低雲端依賴、保護資料、節省能耗與累積數位資產的公益基礎設施。

### 9. 專利與學術授權是社區收入候選路徑

系統可向大學、NPO、長照、醫療、司法、社區組織、管委會等提供 ESG 社會創新沙盒、隱私封裝引擎、邊緣算力治理架構、社區微型經濟體建置與 Odoo 多模組治理模板。但正式對外授權前須經法務、會計、授權合約與人類決策。

## 不能被誤解的邊界

| 原始精神 | 工程/治理邊界 |
| --- | --- |
| 0 EPS | 不等於無會計責任；須保留帳務與稅務審核 |
| ESG 影響力 | 不等於可任意宣稱社會成效；須有量測與證據 |
| 幸福幣 | 不得成為投資商品、法幣替代、未審查金融工具 |
| 分潤 | 不得無合約自動執行；須會計窗與人類確認 |
| 專利授權 | 不得誇稱保證獲利或排他權；須正式專利/合約 |
| 隱私封裝 | 不得輸出會員明文、secret、Odoo 明細或 Google 私人資料 |
| AI 自動化 | 不得自動付款、退款、折扣 override、經理 override |

## 工程落地順序

1. 保留原意：`0 EPS -> ESG` 不變式。
2. Odoo 補模型：基金池、幸福幣、票券、專勤隊、錯帳更正。
3. 補會計窗：analytic account、憑證、準備金率、沖銷。
4. 補法律/合約窗：分潤、授權、加盟、資料使用。
5. 補 ESG 報告窗：只輸出總量、非個資、可稽核指標。
6. 補看板：展示完成度、風險、待建設，不展示敏感明細。
