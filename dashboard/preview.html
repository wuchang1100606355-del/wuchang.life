五常太極｜動態連接埠轉發超連結

用同一個網頁生成不同服務的動態連結：Odoo、WebUI、API、門市設備、Tailscale、區網 IP 都能切。
支援 ?host=&port=&path=&proto=&go=1 參數；可做「開新窗即轉發」。
Dynamic Port Link Hub

1. 目標連線

動態頁連結用途：把本頁網址加上參數分享或設成桌面捷徑，例如 ?host=192.168.50.249&port=8069&path=/web&proto=http&go=1

2. 快速服務卡

服務卡存在瀏覽器 localStorage。換瀏覽器或清除資料會消失，正式部署可改接你的度規記憶庫 / policy file。

3. 新增 / 修改服務卡

建議保留門市內網服務，不要直接把管理後台暴露到公網。對外請走 Cloudflare Tunnel / VPN / 反向代理與登入權限。

4. 常用參數

host：主機或網域 port：連接埠 path：服務路徑 proto：http / https go=1：載入後自動轉跳 delay=1500：自動轉跳延遲毫秒
安全原則：本頁只是產生或開啟 URL，不含密碼、不含 token、不替你繞過登入。若用於公開網域，請在伺服器層加上認證、TLS、存取控制與日誌。
