# Storage Boundary Policy v3: Association Authority Correction

版本：2026-05-11  
修正：本會為社區發展協會，本專案為經會員大會通過之社區產業發展專案  

## 權限語意

本系統涉及之會員、商家、管委會、社區產業資料，應依「本會資訊保護責任」治理。

這些資料不是個別團體會員任意管轄，也不是 AI 可任意擷取的資料。

正確治理鏈：

```text
會員大會授權
→ 社區發展協會治理
→ 社區產業發展專案
→ Taiji Five-Metric Gateway
→ 權限分窗 / Audit / Rollback
```

## C 磁碟

C 磁碟可作為經常讀寫之場景資料資料夾：

- 團體會員資料
- 商家營業資料
- 管委會會議資訊
- POS/Odoo 匯入暫存
- 社區服務案件

但需遵守：

- 本會保護資訊責任
- 權限分窗
- 不自動上雲
- 不直接進外部 AI 明文處理
- 不直接由自然語言改 production

## 組織共用雲端

雲端仍只存：

```text
無敏
唯讀
全設備可用
組織共用
```

雲端不得存：

- 本會受保護會員明文
- 商家營業機密
- 管委會敏感會議資訊
- Odoo/POS 明細
- secret / token / key

## D 磁碟

D 磁碟為高權限特殊用途區：

- 熱資訊
- 特殊用途封存
- 高敏 snapshot
- 本人審查後資料

存取必須：

- 符合公益度規
- 經本人審查
- 記錄在案
- 產生 SHA256
- 保留 rollback reference

## 專案唯一劇本

```text
新北市三重區五常社區發展協會
經會員大會通過之社區產業發展專案
```

其他商業、設備、POS、Odoo、Google、Runtime 設計，均應服務此劇本或依分窗標記為技術支援/私人商業/社區產業等不同身份，不得混淆資產與權限。
