# 摘要 v0.5 TIPO Draft

本發明揭露一種基於多維狀態封包之跨系統人工智慧任務執行治理系統及方法，應用於企業資源規劃系統、組織帳號系統、通訊平台及邊緣運算節點之至少其中之一。該系統包含候選意圖產生模組、多維狀態封包產生模組、陣型工作區映射模組、策略閘道模組、跨系統連接器模組及稽核回放模組。候選意圖產生模組接收自然語言請求或系統任務請求並產生候選操作意圖；多維狀態封包產生模組將該候選操作意圖轉換為包含身分、工作區、資料來源、工具、目標系統、時間及權限尺度之多維狀態封包；陣型工作區映射模組依該封包選定受控工作區；策略閘道模組於外部工具呼叫前產生 allow、warn、block 或 rollback 判斷；跨系統連接器模組僅於 allow 時呼叫受限工具；稽核回放模組記錄候選意圖、封包、判斷、工具呼叫及結果。藉此，人工智慧候選意圖與實際跨系統操作被分離，並可於操作前進行授權、阻斷及稽核回放。
