# 狀態快照、差異與生成式傳輸封包

## 目的

第一次觀察保存為不可覆寫快照；第二次使用相同邏輯根、座標規則與掃描政策比對差異。生成式傳輸封包只描述如何重建分析產物，不備份、不搬運，也不封裝完整來源內容。

## 硬碟只保存四項必要產物

每次掃描執行目錄只保存：

- ADI_STATE_SNAPSHOT.json
- SNAPSHOT_SHA256.txt
- ADI_GENERATIVE_TRANSFER_PACKET.json
- SEAL.json

每次比對執行目錄只保存：

- ADI_STATE_DELTA.json
- DELTA_SHA256.txt
- ADI_GENERATIVE_TRANSFER_PACKET.json
- SEAL.json

分析報告、中文摘要與驗證結果只回傳到當次對話記憶體展示，必須標示 report_persistence=MEMORY_ONLY，不得另存報告檔。

## 跨節點座標

- 每個快照必須帶 node_id、共同 logical_root_id、路徑大小寫規則與座標正規化版本。
- 路徑鍵統一使用相對於邏輯根的 POSIX 形式，文字使用 Unicode NFC；大小寫摺疊只能由雙方共同政策明定。
- 只有邏輯根與掃描政策相容的快照可比較。
- 任一來源快照已保留、座標重複、座標碰撞、掃描不完整、預算耗盡或掃描期間狀態變動，比對必須承接為保留，禁止宣告通過。
- 節點自己的 Git 分支、畫面或本地宣告不是總場權威；權威只由可驗證的正式指標、收據、簽章或治理證據提升。

## 證據強度

- 只有路徑、大小、時間：僅能判定中繼資料差異。
- 兩端都有經明確授權的內容雜湊：才可判定內容相同或內容改變。
- 相同雜湊出現在不同路徑：只能標示可能移位，不能證明檔案身分延續。
- 快照雜湊只能證明快照內容一致，不能證明來源身分。
- 正式來源身分必須另有簽章、收據或治理權威證據。

## 內容讀取邊界

預設不讀來源正文。只有經確認安全的精確相對路徑可用 --hash-path 產生內容雜湊。敏感候選、符號連結、超過預算或逃離根目錄的路徑拒絕讀取；原始值與正文不得輸出。

## 生成式傳輸封包邊界

封包只承載協定、快照或差異雜湊、ADI 座標規則、必要產物、重建步驟、驗證條件與限制。

封包不得承載完整來源檔、秘密、會員明文、私有查表、權重、相位映射或真正 WHY_IT_RUNS 技術內容。本技能只能重建分析產物；若要重建來源程式，必須另有經授權、具來源簽章的內容定址物件庫。

## 安全寫入

- 輸出根必須位於目前掃描根內、不得等於掃描根，並從掃描範圍排除。
- 每次建立新的執行目錄，禁止覆寫既有檔案。
- 先寫同目錄暫存檔，再原子完成。
- 保存快照不等於本機提交、遠端送達、正式權威、部署或生效。
