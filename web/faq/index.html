Public FAQ and misconception guard

常見問題

這頁用來回答外部審查者、居民、商家與協作夥伴最容易誤解的問題。 五常智慧雲可以公開展示方向與原型，但不能把未驗證的能力說成正式上線。

問清楚，才不會誤用 FAQ 是紅隊邊界的一部分：讓小J、8D、付款、會員資料與非營利狀態都被正確理解。
小J

小J是什麼？

小J是主權 AI 個人管家候選層，用來協助理解、整理、提醒與產生候選。它不是身份、付款、會員資料、部署或 release 的權威層。

8D

八維度意圖場封包重構是什麼？

它把人的意圖、狀態、座標、證據、政策、生成、紅隊與封套整理成可審查封包，用人類意圖場治理 AI 幻覺。

身份

我自稱身份，系統會直接相信嗎？

不會。公開頁和小J都不能把一句自稱當成已驗證身份。正式身份需要登入、role_ref、signed identity packet 或 verifier 驗證。

會員資料

網站會讀會員明文嗎？

公開網站不讀會員明文，不顯示身分證字號、完整電話、完整地址或 production DB 會員資料。展示內容是公開說明或沙盒示意。

付款

現在可以付款、刷卡或捐款嗎？

不可以。公開網站沒有啟用付款、刷卡、捐款或 production POS 交易。未完成授權、資料保護與 release gate 前，不新增付款入口。

非營利

五常智慧雲是否尚未取得外部核准？

尚未在公開頁宣稱核准。網站目前是公益/非營利送審準備與公開展示階段，正式資格需要人類提供可查文件。

服務

目前有哪些服務方向？

包含社區公告與活動、物業管理與住戶服務、志工關懷、在地商家協作、POS 沙盒、小J管家與8D治理展示。

上線

這個網站為什麼還不是 production ready？

還沒有。HTTPS/443、正式法人/年度證據、evidence seal、verifier gate、release approval manifest 與伺服器安全標頭仍需補齊。

安全下一步

如果你想了解方向，請先看服務與活動、公益影響、送審資料與公開審查封套。 如果你想聯絡或回報安全問題，請使用聯絡與安全回報頁，不要寄送 token、key、會員明文、付款資料或 raw audio。
