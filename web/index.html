Website Quality

品質與安全邊界

網站品質不只看漂亮，也要可用、可讀、可維護、可稽核，並且不把敏感資訊放到公開頁。

形象頁品質

  • 第一屏先講協會願景公共信任與服務方向優先，工程工具收在平台入口之後。
  • 六平台清楚分流商業聯合銷售、物業管理、會員登入、社區許願樹、社區幣/票券兌換、社區活動各有明確目標。
  • 手機與鍵盤可操作語意導覽、skip link、穩定卡片尺寸與清楚 focus 狀態。

安全承諾

  • 會員資料不公開姓名、電話、地址、ID、raw audio、cookie、OAuth token、API key 不進首頁。
  • 支付不自動扣款管理費只能產生候選支付意圖與支付工具參照，扣款需會員確認與正式流程。
  • AI 不繞過總場小J與雲端候選算力需回到本地 verifier 決定 ALLOW / HOLD / BLOCK。
