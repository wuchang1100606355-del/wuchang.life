Public transparency status

公開透明狀態

這頁用白話列出五常智慧雲目前哪些已公開、哪些只是展示、哪些是沙盒、哪些尚未啟用。 它給居民、協作夥伴與審查者一個不用讀技術封套也能理解的狀態頁。

公開可看，不等於正式上線 production release 仍由總場 HOLD；模型不能把展示狀態升級成正式授權。
公開

可閱讀

首頁、關於、服務、影響、FAQ、隱私、聯絡與審查封套可公開閱讀。

展示

可體驗方向

小J、8D、POS、物業、志工與工作台頁面可展示方向，但不是正式交易或正式會員服務。

HOLD

需總場准駁

身份、權限、會員資料、付款、production DB、部署與 release 需 verifier 與總場封印。

未啟用

不能誤用

捐款、刷卡、會員明文、raw audio、secret、production Odoo/POS 寫入都不在公開頁執行。
