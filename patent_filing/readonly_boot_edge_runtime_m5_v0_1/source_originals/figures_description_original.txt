圖式說明
圖1：唯讀啟動媒體環境注入系統圖：示意唯讀啟動媒體(100)、環境參數擷取模組(110)、執行環境注入模組(120)、瞬態 tmpfs I/O 區(130)、執行環境(140)、稽核日誌模組(150)與回滾模組(160)之間的資料流程。
圖2：Transient Runtime Memory Flow：顯示從啟動掛載 tmpfs I/O 區、應用程式讀寫暫存資料到該區域，並於完成後卸載該區域的流程。
圖3：Runtime Rollback Flow：描述在執行完成時，停止服務、關閉容器、卸載 tmpfs、還原環境變數並釋放資源的步驟。
圖4：Edge Runtime Orchestration：示意環境注入模組與容器協調檔案合作啟動多個服務，並將環境變數傳遞至各服務的流程。
圖5：Execution Authority Chain：示意從唯讀啟動媒體起始的權限鏈，經由環境擷取、環境注入、執行、稽核到回滾的控制流程。
