# 申請專利範圍

1. 一種基於唯讀啟動媒體之邊緣運算執行環境注入、瞬態記憶體調度與執行狀態回復方法，其包含：
   (a) 以唯讀啟動媒體啟動一邊緣節點；
   (b) 於該唯讀啟動媒體完成掛載後且至少一服務程序啟動前，擷取多層環境配置資料，該多層環境配置資料至少包含使用者層配置資料、全域層配置資料及系統預設配置資料；
   (c) 依據一優先序合併規則合併該多層環境配置資料，以產生一執行環境參數集合；
   (d) 將該執行環境參數集合轉換為一五維度規封包，該五維度規封包至少包含節點或身份、資料敏感性、動作意圖、權限時間窗口及可逆性或公共價值；
   (e) 依據該五維度規封包產生一治理判決；
   (f) 依據該治理判決將該執行環境參數集合注入至一容器化或服務化執行環境，其中該注入係透過記憶體中之服務協調設定、環境變數映射或進程啟動參數完成；
   (g) 於一執行工作階段建立時，在揮發性記憶體中配置一瞬態記憶體 I/O 工作區；
   (h) 使該執行環境於該瞬態記憶體 I/O 工作區中進行暫存資料、中間輸出或運行檔案之讀寫，以避免對該唯讀啟動媒體進行寫入；
   (i) 監測該執行工作階段之終止條件，該終止條件包含進程結束、中斷訊號、逾時、錯誤碼或治理判決觸發之至少一者；
   (j) 記錄該執行工作階段之稽核資料；以及
   (k) 於該終止條件成立時，清除該瞬態記憶體 I/O 工作區、解除該注入之執行環境參數集合，並將系統環境回復至該執行工作階段啟動前之狀態。

2. 如申請專利範圍第1項所述之方法，其中該優先序合併規則係依使用者層配置資料、全域層配置資料及系統預設配置資料之預定優先序解決衝突參數。

3. 如申請專利範圍第1項所述之方法，其中該瞬態記憶體 I/O 工作區為記憶體檔案系統、RAM disk、揮發性記憶體映射目錄或平台相容之暫態工作區。

4. 如申請專利範圍第1項所述之方法，其中該治理判決包含允許、稽核、警示、阻斷、要求人類確認及要求回滾之至少一者。

5. 如申請專利範圍第1項所述之方法，其中該治理判決用以決定邊緣節點執行、本地人工智慧模型執行、雲端轉送、延後執行、阻斷執行或隔離執行之其中一者。

6. 如申請專利範圍第1項所述之方法，其中該瞬態記憶體調度係依據記憶體壓力、讀取壓力、寫入壓力、快取命中率、模型載入成本、網路成本、磁碟成本、資料敏感性及重放風險之至少一者執行。

7. 如申請專利範圍第1項所述之方法，其中該稽核資料至少包含啟動工作階段識別碼、執行環境參數集合雜湊值、五維度規封包雜湊值、父雜湊值、治理判決、政策版本、執行事件、錯誤碼、回滾參照、回復結果及時間戳。

8. 如申請專利範圍第1項所述之方法，其中當偵測到重放風險、權限不連續、資料敏感性不符或拓樸不一致時，該執行工作階段被標記為隔離狀態而非直接重放或恢復執行。

9. 如申請專利範圍第1項所述之方法，其中該執行環境參數集合之注入係於服務程序啟動前完成，且該服務程序依據該執行環境參數集合載入其配置內容。

10. 如申請專利範圍第1項所述之方法，其中該回復係由平台對應清除程序執行，該平台對應清除程序可為 Linux 或 Unix shell 程序、Windows PowerShell 程序或其他作業系統相容程序。

11. 如申請專利範圍第1項所述之方法，其中該執行環境注入不將明文個人資料、金鑰、權杖、服務帳戶私密資料或其他私密認證資料寫入該唯讀啟動媒體或外部人工智慧推理內容。

12. 如申請專利範圍第1項所述之方法，其中該唯讀啟動媒體包含政策基準，且該政策基準用以約束該治理判決之產生。

13. 如申請專利範圍第1項所述之方法，其中該五維度規封包進一步包含政策雜湊值、節點簽章、封包有效期限、稽核識別碼或重放防護參數。

14. 一種邊緣運算執行環境治理系統，其包含：唯讀啟動媒體、環境參數擷取模組、封包產生模組、AI 匝道判決模組、邊緣 I/O 記憶體調度器、人工智慧執行期、稽核記錄模組及回復模組；其中該封包產生模組產生五維度規封包，該 AI 匝道判決模組依據該五維度規封包產生治理判決，該邊緣 I/O 記憶體調度器依據該治理判決控制瞬態記憶體 I/O 工作區之讀寫、配置及生命週期。

15. 如申請專利範圍第14項所述之系統，其中該稽核記錄模組以雜湊鏈方式記錄執行事件，以供後續回復、重放防護或稽核驗證。
