# Wuchang Hexagram State Protocol
# 五常卦象狀態協定

This project is a defensive open publication and open-source reference implementation for a local-first edge AI state protocol.

本專案為防衛性公開與開源參考實作，用於低成本社區邊緣 AI、緊急保命通道、本地設備治理與安全降載。

## Core Concepts

- Hexagram State Code / 卦象狀態碼
- 7D Intent State Vector / 七維意圖狀態向量
- Local Life-Safety Reserved Lane / 本地緊急保命通道
- Semantic Brownout / 語意降載
- Local-first AI Gateway / 本地優先 AI 閘道

## Scope

This repository publishes a safe reference model only.

It does not include:

- real device keys
- real community member data
- real emergency routing rules
- private five-dimensional code mappings
- production credentials
- internal deployment secrets
