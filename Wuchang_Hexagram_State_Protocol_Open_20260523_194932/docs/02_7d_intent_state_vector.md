# 7D Intent State Vector / 七維意圖狀態向量

The public reference vector contains seven normalized dimensions:

| Dimension | Meaning |
|---|---|
| trust | source trust score |
| rate | traffic-rate anomaly score |
| entropy | behavior entropy score |
| protocol | protocol validity score |
| role | local role score |
| emergency | life-safety priority score |
| history | historical behavior score |

This repository does not publish production thresholds or private mappings.
